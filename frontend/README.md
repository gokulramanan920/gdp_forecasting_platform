# GDP Forecasting Platform — Frontend

React 18 + Vite + TailwindCSS v4 + Plotly.js frontend for the GDP Forecasting Platform.

See the root [`README.md`](../README.md) for full project documentation.

## Dev server

```bash
npm install
npm run dev   # http://localhost:5173
```

The Vite dev server proxies `/api/*` requests to `http://localhost:8000` (FastAPI).
